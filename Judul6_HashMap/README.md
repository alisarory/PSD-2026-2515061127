# Judul6_HashMap

Final assignment for Data Structure Practicum 6: Hash Map.

## Description

This program implements a simple Hash Map using Python.  
The data is stored in key-value pairs.

The program uses a hash function to determine the index of each key.  
If two keys have the same index, the program handles it using Separate Chaining.

## Features

- Insert data
- Search data
- Delete data
- Display hash map
